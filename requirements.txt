# ==============================================================================
# JiraBot - Requisitos e Dependencias
# ==============================================================================
#
# O nucleo do JiraBot foi desenvolvido para ser altamente nativo e portatil,
# utilizando prioritariamente modulos da Biblioteca Padrao do Python (Standard Library)
# e chamadas diretas a API Win32 do Windows (bloqueio de sessao, system tray, etc).
#
# Para a sincronizacao automatica ao vivo com o Microsoft 365 e SharePoint Online
# (leitura direta de arquivos .docx vivos e extracao de evidencias com resolucao de AADSTS65002),
# e utilizada a biblioteca oficial Microsoft Authentication Library (MSAL).
#
# ------------------------------------------------------------------------------
# Requisitos de Sistema:
# ------------------------------------------------------------------------------
# - Sistema Operacional: Windows 10 ou Windows 11 (64-bit)
# - Versao do Python  : Python >= 3.8 (Testado e compativel com 3.8 a 3.14)
#
# Instalacao rapida das dependencias:
#   pip install -r requirements.txt
#
# Para iniciar o bot, basta dar duplo clique em:
#   iniciar.bat
#
# ==============================================================================
