# ==============================================================================
# JiraBot - Requisitos e Dependencias
# ==============================================================================
#
# O JiraBot foi desenvolvido para ser 100% nativo e portatil, utilizando
# EXCLUSIVAMENTE modulos da Biblioteca Padrao do Python (Standard Library)
# e chamadas diretas a API Win32 do Windows.
#
# PORTANTO: NAO E NECESSARIO INSTALAR NENHUM PACOTE EXTERNO VIA PIP!
#
# ------------------------------------------------------------------------------
# Requisitos de Sistema:
# ------------------------------------------------------------------------------
# - Sistema Operacional: Windows 10 ou Windows 11 (64-bit)
# - Versao do Python  : Python >= 3.8 (Testado e compativel com 3.8 a 3.13)
#
# Modulos nativos utilizados pelo bot:
# - urllib.request   : Integracao HTTP com a API REST do Jira
# - ctypes / wintypes: Monitoramento de bloqueio de sessao (WTS) e System Tray
# - tkinter          : Dialogos graficos de revisao pre-saida
# - dataclasses      : Modelagem tipada de estado e configuracao
# - json / pathlib   : Persistencia local atomica
# - subprocess / sys : Gerenciamento de processos desacoplados (pythonw.exe)
#
# Para iniciar o bot, basta dar duplo clique em:
#   iniciar.bat
#
# ==============================================================================
